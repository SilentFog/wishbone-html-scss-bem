## 🏗 Project Structure

The project follows a structured SCSS architecture and uses the **BEM methodology** to keep styles modular, predictable, and maintainable.

```text
wishbone-html-scss-bem/
├── scss/
│   ├── blocks/         # BEM components (_header.scss, _team.scss, etc.)
│   ├── global/         # Variables, normalize, and base styles
│   └── style.scss      # Main entry point
├── images/             # Media assets and icons
├── index.html          # Main markup
└── style.css           # Compiled stylesheet
```

### BEM Naming

The interface is organized using the **Block → Element → Modifier** approach:

```text
.block
.block__element
.block--modifier
```

This keeps CSS selectors consistent and reduces style conflicts as the project grows.

## 🚀 Quick Start

Follow these steps to get a local development copy up and running.

### Prerequisites

Ensure you have a modern web browser and a local development server.

For example, you can use the **Live Server** extension in Visual Studio Code.

### Installation

1. **Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. **Navigate to the project directory**

```bash
cd wishbone-html-scss-bem
```

3. **Open the project**

Run the project using **Live Server** or another local development server.

4. **Open in browser**

Navigate to the local address provided by your development server.
